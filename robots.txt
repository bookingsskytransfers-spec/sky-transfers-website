# path stops Googlebot CRAWLING it, which does not remove it from the index —
# it strands the URL there as "Indexed, though blocked by robots.txt" and the
# redirect is never seen, so it passes nothing on.
#
# They were blocked here until 21 Sept 2026, which is what triggered the
# "Blocked by robots.txt" notices from Search Console. Leave them crawlable
# until Search Console shows them gone; after that they can stay crawlable,
# since a 301 costs nothing to serve.
